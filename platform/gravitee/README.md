# Gravitee API Management Boundary

**Status:** CONFIGURED REFERENCE / RUNTIME NOT PROVEN

Gravitee is retained because it is a public Estreem technology signal.

Target responsibilities:
- expose Acquiring/Card Processing APIs;
- OAuth2 token validation integration;
- rate limiting;
- correlation headers;
- API versioning and lifecycle;
- threat protection policies;
- partner/merchant plans.

The local POC does not require Gravitee to execute I01-I11. A real deployment may be added with I14 platform packaging.
